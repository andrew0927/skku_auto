# ROS 2 기반 자율주행 차량 설계 및 구현
"ROS 2 기반 자율주행 차량 설계 및 구현" 교재에서 사용하는 프로그램 설치 파일 및 실습 파일을 제공하고 있습니다.

## 수동·자율주행 실행

`src/control/driving/driving.ino`는 사용자가 배선·가변저항 보정 및 수동주행을
검증한 스케치 그대로 사용합니다. ROS 조향 명령은 이 스케치의 범위인 **-7~+7**,
ROS 모터 속도는 아두이노 PWM 범위에 맞춰 **-255~255**로 제한하며
`s<조향>l<왼쪽속도>r<오른쪽속도>\n` 형식으로 전송합니다. 260처럼 범위를 넘는
명령도 실제 전송 전 255로 제한합니다.
실행 스크립트는 아두이노를 업로드하지 않습니다.

```bash
cd ~/ros2_ws
source /opt/ros/humble/setup.bash
colcon build --symlink-install
./run_autonomous.sh cam_num:=4 port:=/dev/ttyACM0 cruise_speed:=255
```

`cam_num`은 실제 카메라 장치 번호에 맞춥니다. 모델은 작업공간의 `best.pt`를
사용하며 CUDA 사용이 가능하면 GPU, 아니면 CPU를 선택합니다. `device:=cuda:0`
또는 `device:=cpu`로 명시할 수도 있습니다.

새 키보드 터미널의 메뉴에서 선택합니다.

| 입력 | 동작 |
| --- | --- |
| `1` + Enter | 수동주행 선택, 초기 속도 0 |
| `2` + Enter | 자율주행 선택, 정지 상태로 대기 |
| Space | 자율 모드에서 시작·일시정지, 수동 모드에서는 정지 |
| 실행 중 `1` / `2` | 정지한 뒤 수동 / 자율 대기 모드로 전환 |
| `w` / `s` | 수동 속도 +10 / -10 (기본 제한 ±255) |
| `a` / `d` | 수동 조향 -1 / +1 (제한 ±7) |
| `x` | 즉시 속도·조향 0, 자율주행 일시정지 |
| `q` / Ctrl+C | 정지 후 전체 실행 종료 |

모션 플래너는 `autonomous_control_signal`에 계산 결과를 발행합니다.
키보드 노드만 `topic_control_signal`로 차량 명령을 전달하므로,
자율 모드 선택만으로 차량이 출발하지 않습니다. **2 선택 후 Space**가 필요합니다.

## 차선 추종과 조정

카메라는 원본 컬러 BGR 640×480 영상을 기본 10Hz로 입력합니다. 회색 변환이나
밝기 보정은 적용하지 않습니다. `input_period:=0.2`로 입력을 5Hz로 낮출 수 있습니다.
모델의 `lane2`를 기본 목표로 사용하고, `lane1`과 `lane2`가 함께 보일 때 측정한
차선 간격이 최근 2초 이내라면 `lane1`으로 `lane2` 중심을 추정합니다.
차선 화면에는 두 클래스의 윤곽과 선택된 목표 지점을 함께 표시합니다.

조향은 경로 오차에 비례해 계산하고 평활화하며, 기본 오프셋은 0입니다.
`steering_gain:=0.1`로 반응을 줄일 수 있습니다. 유효한 lane2 경로로 주행을
시작하면 바로 기본 속도 **255**를 보냅니다. lane1으로 목표 차선을 추정 중일 때는
`estimated_speed`(기본 **200**)로 낮춥니다. 신호등 판단은 기본으로 꺼져 있습니다.

두 차선이 모두 사라져도 새 영상의 검출 결과가 계속 들어오는 경우, 실제 자율주행에서
마지막 유효 조향 명령을 보낸 뒤 최대 `lane_loss_hold`(기본 **0.4초**) 동안
`lane_loss_steering`(기본 **+4**, 우측)으로 꺾으며
감속 없이 `cruise_speed`(기본 **255**)를 유지합니다. 미검출 메시지가
반복돼도 이 제한 시간이 늘어나지 않습니다. 처음 출발하거나 수동/대기 모드에서
차선이 없으면 이 기능으로 출발하지 않습니다. 두 차선 미검출 뒤 직접 인식으로
복귀하면 바로 255를 사용합니다. lane1 기반 추정 시에는 200으로 낮추고,
추정에서 직접 인식으로 돌아오면 `reacquire_hold`(기본 **0.5초**) 동안
200을 유지한 뒤 255로 돌아갑니다.

미검출 유지 시간이 끝나거나 경로 수신이 0.6초, 원본 영상 나이가 1초를 초과하면
정지 명령을 생성합니다. 키보드/제어 명령이 0.5초 이상 끊겨도 시리얼 노드가
정지를 전송합니다. 아두이노 스케치에는 통신 단절 타임아웃이 없으므로 USB 자체를
분리한 경우 ROS에서 정지 명령을 보낼 수 없습니다. 이 경우 모터 전원으로 정지합니다.

## 차량 없이 검증

아두이노와 키보드 노드를 비활성화해 저장된 트랙 사진으로 인식·경로만 실행합니다.

```bash
./run_autonomous.sh enable_serial:=false enable_teleop:=false \
  data_source:=image show_image:=false
```

테스트는 `/dev/pts` 가상 시리얼만 사용하고 실제 차량 USB를 열지 않습니다.

```bash
source install/local_setup.bash
ROS_DOMAIN_ID=92 ROS_LOG_DIR=/tmp/ros2_ws_tests \
  PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python3 -m pytest -q tests
```
